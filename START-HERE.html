دليل محلي مرفق مع ملفات المصدر

الملفات موجودة. التشغيل يحتاج خادمًا.

هذه الصفحة دليل فقط؛ ليست الموقع العقاري، وليست لوحة الإدارة، ولا تتصل بقاعدة بياناتك.

عدم وجود index.html لا يعني أن التنزيل ناقص

المشروع مبني على Next.js. الصفحة الرئيسية في src/app/(site)/page.tsx، وليست index.html أو indx.html. لا يعمل التطبيق بالنقر المزدوج على ملف، ولا على استضافة HTML ثابتة فقط.

١. تأكد من كل ملفات النسخة

فك ZIP بالكامل، ثم افتح الطرفية داخل مجلد arabic-real-estate الذي يحتوي على package.json. بعد تثبيت Node.js، شغّل:

node scripts/verify-download.mjs
node scripts/check-deployment.mjs --files-only

قائمة PROJECT-FILES.json تضم ملفات التسليم والمسارات المطلوبة. بعد تثبيت الحزم شغّل node scripts/check-source.mjs لفحص الاستيرادات والحزم ومسارات التطبيق. التحميل الكامل يحتفظ بالملفات المخفية الآمنة.

التحقق الأول يراجع كل ملف مقابل قائمة PROJECT-MANIFEST.json المرفقة وبصماته. نفّذه قبل تعديل أي ملفات. تأكد من إظهار الملفات المخفية مثل .env.example و.gitignore.

٢. جهّز الإعدادات وشغّل التطبيق

  1. ثبّت Node.js 22 LTS وجهّز PostgreSQL.
  2. شغّل npm ci --include=dev لتثبيت الحزم من ملف القفل.
  3. انسخ .env.example إلى .env وأدخل اتصال قاعدة البيانات وسر الجلسة وبيانات تهيئة المالك الخاصة بك. لا تستخدم أسرارًا أو كلمة مرور افتراضية منشورة.
  4. شغّل الأوامر التالية لإنشاء الجداول ثم تهيئة المالك ثم التطوير المحلي:
npx drizzle-kit push --config=drizzle.config.ts
npx tsx scripts/seed.ts
npm run dev

بعد بدء الخادم افتح الموقع على localhost:3000، وللدخول افتح لوحة الإدارة. هذه الروابط لا تعمل قبل تشغيل الخادم على جهازك.

٣. ما الذي لا يدخل في حزمة المصدر؟

node_modules و.next
يتولّدان عند تثبيت الحزم والبناء؛ عدم وجودهما طبيعي.
ملف .env والأسرار
غير مرفقة لحمايتك. القالب الفارغ فقط هو الذي يدخل في الحزمة.
قاعدة البيانات وصور uploads
تحتاج نقلًا ونسخًا احتياطيًا منفصلًا وآمنًا. حزمة المصدر ليست نسخة احتياطية لمعلومات العملاء.

للنشر على الإنترنت

استخدم استضافة Node.js مع PostgreSQL وتخزين صور دائم. اقرأ README.md ودليل النشر العربي؛ لا ترفع هذه الملفات باعتبارها موقعًا ثابتًا جاهزًا.

حزمة ZIP تُنزّل من قسم «النشر والروابط» بحساب المالك، ولا تقوم بالنشر أو شراء دومين.

يمكن فتح هذا الدليل بدون إنترنت. التفاصيل والأوامر لا تحتوي بيانات دخول حقيقية.
